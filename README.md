# 🔳 QR Code Generator

A simple and beginner-friendly **QR Code Generator** built using **Node.js**.  
This project allows users to generate QR codes instantly from any text or URL.

---

## 🚀 Features

- Generate QR codes from text or links
- Uses Node.js and npm packages
- Lightweight and easy to understand
- Beginner-friendly project structure

---

## 🛠️ Tech Stack

- **Node.js**
- **npm**
- **JavaScript**
- **QR code generation library**

---

## 📦 Prerequisites

Before running this project, make sure you have:

- **Node.js** installed  
  👉 Download from: https://nodejs.org  
- **npm** (comes with Node.js)

Check installation:
```bash
node -v
npm -v
````

---

## 📥 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/MominulMoon/QR-Code-Generator.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd QR-Code-Generator
```

### 3️⃣ Install Dependencies

```bash
npm install
```

---

## ▶️ Run the Project

Start the application using:

```bash
node index.js
```

or (if using nodemon):

```bash
nodemon index.js
```

---

## 🌐 Open in Browser

After running the server, open your browser and go to:

```
http://localhost:3000
```

(Port number may vary — check your terminal output)

## 💡 How It Works

1. User inputs text or a URL
2. Node.js processes the input
3. A QR code is generated instantly
4. QR code can be scanned using any QR scanner
